# Character Consistency - Notes From Building

The fastest way to break immersion is a character who forgets who they are.

Consistency means the same values, the same speech patterns, and the same history across every session - even after weeks away.

It is easy to demo and hard to sustain, because every new piece of context is a chance to drift.

Consistency is a constraint you enforce, not a hope you have.

These are the lessons that only show up once you ship. [explore Pogee](https://www.pogee.ai).
